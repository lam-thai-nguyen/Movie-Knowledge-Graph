\begin{abstract}
    This work presents a Linked Open Data application for a movie knowledge
    graph. Movie metadata and credit relationships are collected from TMDB,
    transformed into RDF using stable resource URIs, and described with
    Schema.org vocabulary. A manually authored OWL ontology adds semantic
    constraints and inference rules for movies, people, roles, ratings, and
    production entities. Local movie resources are linked to DBpedia and
    Wikidata using identifiers, titles, and release years, with uncertain
    candidates separated from approved links. The resulting graph is
    evaluated through SPARQL questions of increasing expressiveness,
    including basic retrieval, multi-condition filtering and ranking,
    reasoning-based relationship discovery, and cross-knowledge-graph
    querying. The results show that the graph supports both direct metadata
    access and derived or externally enriched information. While the current
    dataset is a bounded snapshot and depends on source completeness and
    remote endpoint availability, it provides a practical foundation for
    semantic movie data integration and Linked Open Data exploration.
\end{abstract}
